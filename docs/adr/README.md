# Architecture Decision Records (ADR)

Este diretório contém documentação de decisões arquiteturais importantes do projeto FiscalAI.

Cada arquivo ADR segue o padrão:
- **Status:** Proposed, Accepted, Deprecated, Superseded
- **Context:** Que problema/limitação levou a esta decisão
- **Decision:** O que foi decidido
- **Consequences:** Trade-offs e implicações
- **Alternatives:** Outras opções consideradas
